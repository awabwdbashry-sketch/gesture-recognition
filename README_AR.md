# ✋ التعرف على إيماءات اليد

مشروع يعتمد على **رؤية الكمبيوتر (Computer Vision)** للتعرف على مجموعة من إيماءات اليد في الوقت الحقيقي باستخدام كاميرا الويب.

يستخدم المشروع **MediaPipe** لاكتشاف اليد وتحديد نقاطها الرئيسية، بينما يستخدم **OpenCV** لمعالجة الفيديو المباشر القادم من الكاميرا.

من خلال تحليل مواقع نقاط اليد وحالة الأصابع، يستطيع البرنامج التعرف على إيماءات مختلفة مثل **القبضة، الإعجاب، عدم الإعجاب، إصبع واحد، السلام، اليد المفتوحة، وإشارة OK**.

## ✨ المميزات

- ✋ تتبع اليد في الوقت الحقيقي
- 🤖 التعرف على إيماءات اليد مباشرة
- 🎥 الاعتماد على كاميرا الويب
- 🧠 تصنيف الإيماءات اعتمادًا على نقاط اليد
- 👊 التعرف على إشارة القبضة
- 👍 التعرف على إشارة الإعجاب
- 👎 التعرف على إشارة عدم الإعجاب
- ☝️ التعرف على إصبع واحد
- ✌️ التعرف على إشارة السلام
- 🖐️ التعرف على اليد المفتوحة
- 👌 التعرف على إشارة OK
- ⚡ معالجة سريعة في الوقت الحقيقي
- 📊 عرض الإيماءة التي تم التعرف عليها على الشاشة

## 🛠️ التقنيات المستخدمة

- 🐍 Python
- 👁️ OpenCV
- ✋ MediaPipe

## ⚙️ كيف يعمل المشروع؟

يقوم البرنامج أولًا بالتقاط الفيديو المباشر من كاميرا الويب باستخدام OpenCV.

بعد ذلك يقوم **MediaPipe** باكتشاف اليد وتحديد مجموعة من النقاط الرئيسية التي تمثل هيكل اليد.

يقوم البرنامج بتحليل العلاقات بين هذه النقاط لمعرفة وضع الأصابع، وتحديد ما إذا كانت الأصابع مرفوعة أو مطوية.

بعد تحديد حالة الأصابع، تتم مقارنة وضع اليد مع مجموعة من أنماط الإيماءات المحددة مسبقًا.

عند اكتشاف تطابق مع إحدى الإيماءات، يتم عرض اسم الإيماءة على الشاشة في الوقت الحقيقي.

## 🧠 منطق التعرف على الإيماءات

يعتمد نظام التعرف على الإيماءات على **المواقع النسبية لنقاط اليد**.

يقوم البرنامج بفحص الأصابع لمعرفة أي منها مرفوع وأي منها مطوي، بالإضافة إلى تحليل ترتيب ومواقع نقاط اليد المهمة.

وتشير مجموعات مختلفة من حالات الأصابع إلى إيماءات مختلفة.

هذا الأسلوب يوفر طريقة بسيطة وعملية لبناء نظام للتعرف على الإيماءات دون الحاجة إلى تدريب نموذج منفصل لكل إيماءة.

## 📦 التثبيت

قم بتحميل المشروع:

```bash
git clone https://github.com/awabwdbashry-sketch/gesture-recognition.git
cd gesture-recognition
```

أنشئ بيئة افتراضية:

```bash
python -m venv venv
```

قم بتفعيل البيئة الافتراضية في Windows:

```bash
venv\Scripts\activate
```

ثم قم بتثبيت المكتبات المطلوبة:

```bash
pip install -r requirements.txt
```
